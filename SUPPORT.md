# Support

Octopus is an open-source project maintained on a best-effort basis.

- **Getting started:** Follow the [README](README.md), including Demo Mode, installation, and configuration.
- **Architecture and internals:** See [ARCHITECTURE.md](ARCHITECTURE.md) and the documentation in [docs/](docs/).
- **Bug reports:** [Open a bug report](https://github.com/bala2006/octopus/issues/new/choose) with steps, your OS, relevant logs (redacted), and expected versus observed behavior.
- **Feature requests:** [Suggest an improvement](https://github.com/bala2006/octopus/issues/new/choose) with the problem, intended users, and possible solution.
- **Contributions:** See [CONTRIBUTING.md](CONTRIBUTING.md).
- **Security vulnerabilities:** Follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
- **Community conduct:** See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

For reproducibility, include the Octopus commit/version, Python and Node versions, and whether you're using native setup, Docker, Demo Mode, or a real model endpoint. Remove all secrets and personal information from screenshots and logs before posting.

The maintainer cannot guarantee response times, individual troubleshooting, or acceptance of suggested changes.
