# Visual review
1. Start the dev server with start_dev_server and open the URL.
2. Read the console. An error on load is a finding.
3. Screenshot each view the change touches at 1280 px and at 390 px wide.
4. Compare each screenshot with the user's words, element by element: layout, spacing, type sizes, colors, images and any motion they asked for.
5. Check the states: empty, loading, error, long text and many items. Create them through the UI or with test data.
6. Check the basics: body text contrast of at least 4.5 to 1, a visible focus ring on every control, every control reachable with Tab, and nothing overflowing at 390 px.
7. Report at most ten findings, most important first.
