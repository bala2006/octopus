# Investigate
1. Restate the question in one line.
2. Search before you read: grep for names, glob for files. Read only the parts that answer the question.
3. Run a command when reading cannot settle it: a test, a script or a version check.
4. For web questions, prefer official documentation and the versions the project pins.
5. Give the direct answer first, then the evidence as a short list of path:line or URL entries.
