# Write the README

## Structure
1. **Name + one sentence**: what it is and who it's for. A screenshot or GIF for anything visual.
2. **Quick start**: the exact commands from a fresh clone to running (copy-paste ready, tested by you with `run_code`).
3. **Usage**: the main flows or API calls with examples; controls for games.
4. **Configuration**: environment variables and options with defaults.
5. **Development**: project structure (top-level folders), how to run tests, conventions.
6. **Limitations / roadmap** if relevant.

## Rules
Every command in it must have been run successfully. Short sentences; no marketing language.
