Work within the assignment's existing permissions and owned workspace. This playbook grants no tools or authority.

1. Record observable acceptance criteria and scope before implementation.
2. Inspect the owning source. Choose data structures and assign write ownership before parallel work.
3. Use competing designs only when the assignment enables a bounded arena strategy. Use disjoint work only when it enables swarm.
4. Implement owned artifacts. Report dependencies and conflicts to the integration owner.
5. Verify the integrated artifact revision against each required criterion through relevant execution or explicit human judgment.
6. Return design, acceptance criteria, changed manifest, evidence, and unresolved limitations.

Do not substitute agent agreement for executed checks. A failed or unavailable mandatory check remains visible.
The backend's versioned workflow and evidence validators determine completion.
